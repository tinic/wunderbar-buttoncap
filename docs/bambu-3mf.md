# Bambu Studio project 3MF: parts, filaments and multi-diameter nozzles

Notes on the Bambu Studio 3MF project format as `tools/plate.py` writes it, found by reading
projects saved by Bambu Studio 2.9.1 for the Bambu Lab H3C (9-nozzle rack, single extruder).

## What `tools/plate.py` writes

| File | Content |
|---|---|
| `3D/3dmodel.model` | Standard 3MF core. One mesh object per part, one parent object per cap with two `<component>`s (Cap, Label), one `<build><item>` per cap with its plate position. The metadata `Application` = `BambuStudio-<version>` and `BambuStudio:3mfVersion` = `1` make Bambu Studio read the Bambu files below. |
| `Metadata/model_settings.config` | XML. Per object: `name` and `extruder` (the object's default filament). Per part (`<part id>` = the component's object id): `name`, `matrix`, `extruder`. One `<plate>` with a `<model_instance>` per object. |
| `Metadata/project_settings.config` | Optional (spec key `project_settings`). JSON with every printer, process and filament setting. Copied as is from a project saved in Bambu Studio. |

`extruder` is the **filament** number, 1-based, in the project's filament list, not a physical
extruder or nozzle.

Bambu Studio saves the same thing in its own layout: one `3D/Objects/object_N.model` per object,
referenced with `p:path` from `3D/3dmodel.model`, and more part metadata (`source_*`, `uuid`,
`mesh_stat`). It reads the single-file layout above too.

## Without `project_settings.config`

Bambu Studio shows "The 3mf was generated by an old version of Bambu Studio, loading geometry
data only". It loads the objects, parts and per-part `extruder` numbers, and keeps the printer,
process and filament list it has. It also switches the H3C to **Single-diameter mode** (0.4),
so letters set to a 0.2 mm spool print with a 0.4 mm nozzle.

## Multi-diameter mode (H3C)

`project_settings.config` keys that set it up, as saved for this printer:

| Key | Saved value | Meaning |
|---|---|---|
| `multi_nozzle_diameter_mode` | `"1"` | Multi-diameter mode on |
| `extruder_nozzle_count` | `["9"]` | Nozzles on the rack |
| `extruder_nozzle_diameter` | `["0.4","0.4","0.2","0.4","0.4","0.2","0.4","0.4","0.4"]` | Diameter of each rack nozzle (rack slots 1 to 9) |
| `extruder_nozzle_volume_type` | `[..., "TPU285", ...]` | Hotend type of each rack nozzle (slot 8 is the TPU hotend) |
| `filament_diameter_map` | `["0.4","0.4","0.2","0.4","0.4","0.4","0.4","0.2"]` | Nozzle diameter each **filament** prints with |
| `filament_nozzle_map` | `["0","0","2","0","0","0","0","2"]` | Rack nozzle index (0-based) per filament: `2` is the third nozzle, a 0.2 mm one |
| `filament_settings_id` | `"Bambu PETG Matte @BBL H3C 0.2 nozzle"` for filaments 3 and 8 | Filament presets have a variant per nozzle diameter; a filament on a 0.2 mm nozzle uses the `0.2 nozzle` preset |
| `filament_colour` | `["#FFFFFF","#D6001C",...]` | Colour of each filament (8 here) |
| `filament_map_mode` | `"Auto For Flush"` | How filaments are assigned to nozzles |
| `print_settings_id` | `"0.20mm Standard @BBL H3C"` | Process; the sidebar shows it as "Multi-diameter 0.20mm Standard" |
| `printer_settings_id` | `"Bambu Lab H3C 0.4 nozzle"` | Printer preset |

The `<plate>` in `model_settings.config` has `filament_map_mode` (`"Auto For Match"` in the saved
project) and `filament_volume_maps` (one `0` per filament).

## The filament slots of this printer

`plates/bambu/h3c-multi-diameter.json` is the `project_settings.config` of the H3C as synced from
its AMS on 2026-11-25. Its filament list, which the plate specs in `plates/` follow:

| Filament | Colour | Nozzle | Used for |
|---|---|---|---|
| 1 | White (PETG Matte) | 0.4 | White caps |
| 2 | Red (PETG Basic) | 0.4 | Red caps and letters |
| 3 | White (PETG Matte) | 0.2 | White letters |
| 4 | Green (PETG Basic) | 0.4 | Green caps and letters |
| 5 | Grey (PETG Basic) | 0.4 | Grey caps |
| 6 | Black (PETG Matte) | 0.4 | Black caps |
| 7 | Blue (PETG Basic) | 0.4 | Blue caps and letters |
| 8 | Black (PETG Matte) | 0.2 | Black letters |

When the spools change: sync the printer in Bambu Studio, set each filament's nozzle, save any
project, and copy its `Metadata/project_settings.config` over the template. Then update the
`filaments` and `letter_filaments` slots in the plate specs.
