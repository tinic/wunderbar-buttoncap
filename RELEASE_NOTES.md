Storage tray: the caps now stay on.

- Each peg has a collar that the snap rib inside the cap clicks over, so the caps stay on the tray when it is bumped. A light pull takes a cap off. Long-cap pegs do the same with the long cap's ridge.
- Print `CapTray-fit-coupon.3mf` first. To change the hold, set `collar_d` (round) or `lcollar_w` (long) in `cad/tray/CapTray.sc` and run `make tray`.
- Caps: the same 458 round and 26 long caps as v0.9.0.
